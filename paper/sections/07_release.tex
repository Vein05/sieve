\section{Data and Code Release}
\label{sec:release}

This study builds on the \textbf{ragscale} interaction matrix released with
\citet{panthi2026fixed}: we use that paper's dataset as the substrate for all
policy, oracle, and transfer analyses here, and extend it. We release: (1) the
\textbf{new analysis layer} --- policy-ladder, leave-family-out transfer, and
oracle noise-correction code (every table regenerates in $\sim$2 minutes on a
laptop, offline); (2) the \textbf{cells added for this study} --- the
summary-policy cells, the additional reader completing the 21-reader panel, and
the 2{,}000-call format-probe run with its byte-identity-tested harness; (3) the
\textbf{P3 cross-benchmark mechanism analysis} over the matrix's held-out
benchmark cells. MIT license. The dataset contribution of the prior paper is not
re-claimed here; this paper's artifact is the analysis layer and the extension
cells.
